# Photo names the page expects

Rename your photos to these names (any of .jpg / .jpeg / .png), drop them in this folder,
then run `bash scripts/optimize-photos.sh`. Any photo that's missing shows as a burgundy
placeholder with its label, so the page never looks broken.
